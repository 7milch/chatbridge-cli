chatbridge TUI Competition

Four visual directions for the interactive mode, each shown in the same three states with the same conversation. Everything drawn here uses only what OpenTUI can render: cell colours, bold, inverse, box borders. No images, no proportional fonts.

  • 80 × 24 cells, dark terminal
  • State 1: waiting for a reply (spinner + elapsed / budget)
  • State 2: @ file popup open
  • State 3: mention error, input kept

5Pick · Codex labels + Claude Code input

Direction 2's header badge and bold role names, with direction 1's input: a bare > between two hairlines. The popup follows the input's idiom and opens below it, as a plain indented list. Saves two rows against the rounded box.

Input height: one row when empty, growing with each newline up to five rows; beyond that the textarea scrolls internally. The history shrinks to make room and the hairlines move with it, as in Claude Code.

Banner wiring: createCli({ name, provider, banner }) where banner is an array of lines (optionally { text, color } per line) or a function of the terminal width. Rendered centred in the empty history and removed when the first message arrives. Default when unset: name, version, and the one-line hint above.
