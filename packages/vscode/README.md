# @chatbridge/vscode

VSCode extension factory for [chatbridge](https://github.com/7milch/chatbridge-cli): `createExtension` turns a chatbridge Provider into a sidebar chat view that a vendor ships as its own extension.

```bash
npm install --save-dev @chatbridge/vscode
```

## Documentation

- [Using the VSCode extension](https://github.com/7milch/chatbridge-cli/blob/main/docs/users/vscode.md): commands, settings, composer, attachments
- [Shipping an extension with `createExtension`](https://github.com/7milch/chatbridge-cli/blob/main/docs/providers/define-provider.md): options, the manifest a vendor must carry, packaging a `.vsix`
